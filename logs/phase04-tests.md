## 测试
- Edge：三尺寸 3:2 与一屏布局、行走启停、减少动态效果、资源和 JS 错误检查通过。
- Edge 子路径：23 项核心浏览器回归、17 组实际位移速度采样通过。物理速度 175 px/s，E 监听器 1 个。
- Chrome：使用官方免安装 Chrome for Testing（系统安装失败后下载），在相同纯静态子路径运行视觉、核心交互、速度与八方向/焦点检查，结果见相应 JSON。
- 八方向输入：四个轴向与四个斜向模长均为 175；弹窗初始焦点、Tab 不进入背景页面、Esc 返回通过。原生 dialog 的 Tab 可经过浏览器工具栏，测试允许 activeElement 为 body，不把它误判为页面内焦点逃逸。
- 日期变化、概率边界/十万次抽样、损坏存储、禁用存储和媒体降级由核心测试覆盖；浏览器覆盖同日恢复、刷新、动画中断及存储异常。
- 依赖 npm audit 零漏洞，没有新增生产依赖。
- 生产静态子路径服务 4183：加载和刷新通过，无必要资源缺失。未执行 GitHub Actions，未公开部署，不能替代公网验收。

## 性能与资源
Phase 03：JS 1504.38 KB / gzip 353.81 KB；原始 PNG 约 55.98 KB。
Phase 04：JS 1506.15 KB / gzip 355.39 KB；CSS 2.75 KB / gzip 1.23 KB；PNG 合计 33037 字节，地面 PNG 25.71 KB。细节生成中间地面曾约146 KB，经调色板压缩显著减少。小图会内联 JS，不应将源码 PNG 合计再重复计入所有传输量。
本机 Edge 五次短采样约59.5–60 FPS；heap 约12.3–13.6 MB，有回收下降；监听器数量为1。不是长时间泄漏或 CPU 分析证明。performance.json 保存页面与资源时序，ready 字段采集于短采样之后，不作为 Phaser 初始化耗时。未做严格首次加载基准或持续 CPU profiling。
Phaser 全量引擎为大包主要来源，未为消除提示强行改架构。浮尘仅8个，纹理按 preload 加载一次，无新外部字体/图像请求。
