# Phase 04 性能检查

最终生产构建 JS 1506.15 KB / gzip355.39 KB；CSS2.75 KB / gzip1.23 KB；8张PNG合计33037字节，地面25.71 KB。图片细节增加但源码PNG比Phase03合计约56KB更小，来自限色PNG编码。小图内联JS，不重复统计传输。
本机Edge短采样约59.5–60 FPS，堆约12.3–13.6MB并出现回收下降；每轮E监听器为1。原始值与资源加载时序见phase04-performance.json。没有长期CPU采样或严格内存泄漏验证；不将这些短测宣称为长期稳定性证明。
Phaser全量引擎仍为bundle主要来源，大包提示保留；未为消除提示大规模重构。8个环境浮尘，无新增运行时依赖。必要纹理只在preload加载，静态子路径验收无缺失资源。

补测 initializationMs=769 ms：从当前本机页面导航时间原点，到测试发现 Phaser 角色已创建的时刻；包含轮询开销，不是引擎纯初始化耗时，也不是公网首次加载基准。
